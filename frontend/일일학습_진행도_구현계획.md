# 일일학습 진행도 저장 및 이어하기 구현 계획

## 현재 상황 분석

### ✅ 이미 구현된 것
- **Backend**: `DayProblem` 엔티티에 `isCompleted` 필드 존재
- **Backend**: 완료/미완료 문제 조회 API 있음
- **Backend**: 문제는 `seqNo` (1-10) 순서로 관리됨
- **Frontend**: `getDailyProblems()` API로 미완료 문제 가져오기 가능
- **Frontend**: `submitSingleProblemResult()` 함수 준비됨

### ❌ 구현되지 않은 것
- **Backend**: 정답 제출 API 엔드포인트 없음 (`POST /api/student/{studentId}/adventure/result`)
- **Backend**: 문제 완료 상태 업데이트 로직 없음
- **Frontend**: 진행 상황에 따른 이어하기 로직 없음

---

## 제안하는 설계

### 1. 라우터 설계 (추천)

**옵션 A: URL에 idx 제거 (추천)**
```
/daily/:studentId
```
**이유**:
- 백엔드가 진행도를 관리하므로 URL에 idx 불필요
- 페이지 진입 시 백엔드에서 다음 풀어야 할 문제 가져옴
- URL 조작으로 건너뛰기 원천 차단
- 더 깔끔한 UX

**옵션 B: URL에 idx 유지**
```
/daily/:studentId/:idx?
```
**이유**:
- 새로고침 시 현재 보던 문제 유지 (빠른 UX)
- 하지만 백엔드 검증 필요 (건너뛰기 차단)

**추천: 옵션 A**

### 2. Backend API 구현 필요사항

#### API 1: 진행도 조회 (이미 있음)
```
GET /api/student/{studentId}/adventure/daily
응답: {
  problems: [
    { dayProblemId, seqNo, adventureTypeId, isCompleted, ... }
  ],
  nextProblemIndex: 3  // 다음에 풀어야 할 문제 인덱스
}
```

#### API 2: 정답 제출 (새로 구현 필요) ⭐
```
POST /api/student/{studentId}/adventure/result
Body: {
  dayProblemId: 123,
  isCorrect: true,
  attemptCount: 2,
  submittedAt: "2025-01-01T12:00:00Z"
}
응답: {
  success: true,
  nextProblemId: 124,  // 다음 문제 ID (없으면 null)
  completedCount: 4,   // 총 완료 문제 수
  totalCount: 10
}
```

**로직**:
1. `dayProblemId`로 문제 조회
2. `isCompleted = true` 업데이트
3. 다음 미완료 문제 찾기 (seqNo 순서로)
4. 완료율 계산해서 반환

### 3. Frontend 로직 수정

#### DailyRunner.tsx 수정

**현재 로직**:
```typescript
// 모든 문제를 가져와서 ProblemRunner에 전달
const problems = await getDailyProblems(studentId);
```

**수정 후 로직**:
```typescript
// 1. 미완료 문제만 가져오기
const response = await getDailyProblems(studentId);
const incompleteProblems = response.problems.filter(p => !p.isCompleted);

// 2. 이미 모두 완료했으면 완료 화면 표시
if (incompleteProblems.length === 0) {
  return <AdventureCompletionScreen />;
}

// 3. 첫 번째 미완료 문제부터 시작
<ProblemRunner
  problems={incompleteProblems}
  currentIndex={0}  // 항상 0부터 (이미 필터링됨)
  mode="daily"
/>
```

#### ProblemRunner.tsx 수정

**1. URL에서 idx 제거 (옵션 A 선택 시)**
```typescript
// 제거
const { idx } = useParams<{ idx?: string }>();

// 제거 또는 주석처리
useEffect(() => {
  if (mode === 'daily') {
    navigate(`/daily/${studentId}/${currentIndex}`, { replace: true });
  }
}, [currentIndex, mode, studentId, navigate]);
```

**2. 정답 제출 후 백엔드 응답 활용**
```typescript
const handleSubmit = async (answer: unknown, attempts: number) => {
  const result: AnswerResult = {
    dayProblemId: currentProblem.dayProblemId,
    studentId: currentProblem.studentId,
    isCorrect: true,
    attemptCount: attempts,
    submittedAt: new Date().toISOString(),
  };

  try {
    // 백엔드에 제출
    const response = await submitSingleProblemResult(studentId, result);

    // 다음 문제가 있으면 이동
    if (currentIndex < problems.length - 1) {
      setCurrentIndex(prev => prev + 1);
    } else {
      // 모든 문제 완료
      setIsAllCompleted(true);
    }
  } catch (error) {
    console.error('제출 실패:', error);
  }
};
```

### 5. 건너뛰기 방지

**옵션 A (URL에 idx 없음)**: 자동 방지됨
- URL 조작 불가능
- 백엔드가 다음 문제만 제공

**옵션 B (URL에 idx 있음)**: 백엔드 검증 필요
```typescript
// Frontend: URL의 idx가 허용 범위인지 확인
useEffect(() => {
  // 백엔드에서 완료된 문제 개수 가져오기
  const checkProgress = async () => {
    const progress = await getStudentProgress(studentId);
    const urlIdx = parseInt(idx, 10);

    // 완료된 문제 개수보다 큰 인덱스 접근 시도 시 리다이렉트
    if (urlIdx > progress.completedCount) {
      navigate(`/daily/${studentId}/${progress.completedCount}`, { replace: true });
    }
  };
  checkProgress();
}, [idx]);
```
